# 🔬 Deep Research

Structured deep research skill for [OpenClaw](https://github.com/openclaw/openclaw).

**Parallel collection → local evidence persistence → offline synthesis → adversarial self-review → delivery.**

Use this skill whenever you want to understand a topic in depth — competitive landscape, technology selection, industry trends, academic survey, or any question that requires multi-source evidence gathering and rigorous analysis.

## Features

- Parallel web search and source collection
- Evidence persistence to local files for offline review
- Multi-round synthesis with adversarial self-review
- Structured delivery with citations

## Installation

```bash
openclaw skills install deep-research
```
