# 写作风格指南

> 适用于 deep-research 报告输出，尤其在 hv（横纵）模式下严格执行。
> 也可被 Editor Agent 等其他写作场景引用。

## 叙事技法

### 1. 节奏感
句子时长时短，段落之间跳跃自然。不要每段一样长。一句话自成一段可以制造重量感。好的节奏像波动——每次围绕主线偏出去一点，再用一句"扣主线句"拉回来。

### 2. 叙事驱动，不是罗列驱动
有起承转合，不是"2023年1月发布A，3月发布B"流水账。一个产品为什么在某个时间点突然爆发？背后的铺垫是什么，转折是什么？把这些讲清楚。

### 3. 知识自然带出
在讲述过程中自然地带出背景知识——"聊着聊着顺手掏出来"。不要"下面我来给大家科普一下"。

### 4. 敢下判断
鼓励给出观点和洞察，但每个观点必须有事实支撑。先摆事实，再给判断。是推测的明确标注。表达判断时用"我的判断是""我觉得"承认主观性，而不是居高临下的定论。

### 5. 层层剥开
不直接讲结论。用"现象→表面解释→更深的追问→核心洞察"的方式展开，让读者参与思考过程。

### 6. 回环呼应
开头或前文埋的细节和钩子，在后文 callback 回来。前后因果的闭合感，是让报告从"信息流"变成"作品"的关键。

### 7. 用人话写
用具体的细节和例子代替概括性陈述。不要写"该公司在这一阶段实现了快速增长"，要写"从2024年中期的1000万美元ARR到2025年底的10亿美元，增长曲线几乎是垂直的"。

## 绝对禁区（AI 味标记）

以下标记无论什么文体都必须避免：

| 类型 | 具体表达 |
|------|---------|
| 套话 | "首先...其次...最后"、"综上所述"、"值得注意的是"、"不难发现"、"毫无疑问" |
| 空洞词 | "赋能"、"抓手"、"打造闭环"、"深度融合"、"底层逻辑"（用于装饰而非精确表达时） |
| 教科书开头 | "在当今AI快速发展的时代"、"随着技术的不断进步"、"众所周知" |
| 高频踩雷词 | "说白了"、"意味着什么？"、"这意味着"、"本质上"、"换句话说"、"不可否认" |
| 空泛指代 | "AI工具"、"某个模型"——必须说具体名字 |
| 编造 | 搜不到的信息标注"暂缺"或"[信息未公开]"，绝不编造 |

## 文体尺度适配

| 维度 | 研究报告 | 公众号文章 |
|------|---------|-----------|
| 口语化密度 | 低，偶尔点缀 | 高，全篇聊天感 |
| 小标题 | 必须有清晰章节结构 | 追求一口气读完不加标题 |
| 冒号/破折号 | 正常使用 | 尽量避免 |
| 「」用法 | 保留 | 保留 |
| 表格 | 可自由使用 | 谨慎使用 |

## 自检清单

写完后过一遍：
- [ ] 有没有连续 3 段以上结构完全相同？（有则调整节奏）
- [ ] 有没有触犯禁区里的任何一条？
- [ ] 关键判断有没有事实支撑？
- [ ] 开头埋的钩子有没有在后文回收？
- [ ] 读出来像人写的还是像 AI 写的？
